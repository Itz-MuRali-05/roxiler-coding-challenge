## Installation

Clone the repository:

```bash
git clone <your-github-link>
```

Install dependencies:

```bash
npm install
```

Run frontend:

```bash
npm run dev
```

Run backend:

```bash
npm start
```

## Environment Variables

Create a `.env` file and configure:

```env
PORT=
DATABASE_URL=
JWT_SECRET=
API_KEY=
```
